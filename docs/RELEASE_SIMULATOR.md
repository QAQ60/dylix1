# 发布说明

由 GitHub Actions 构建的 Dylix 模拟器包（含 WorkBuddy AI 服务商适配）。

- `Dylix-simulator.zip`：`TheosMobileCompiler.app`，x86_64 模拟器版，只能在 Mac 的 iOS 模拟器中运行。
- `build.log`：完整构建日志。

这不是可安装到真机的 IPA：真机安装需要你自己的签名证书与描述文件，本仓库不附带任何个人签名材料。

源码基于 https://github.com/yangokok886/dylix （GPL-3.0-or-later），改动见 `workbuddy` 分支与 CHANGELOG。
